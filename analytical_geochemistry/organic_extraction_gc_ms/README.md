## 1. 实验目的

- 掌握从烃源岩粉末中提取可溶有机质的微波萃取方法
- 学习柱层析技术将总有机提取物分离为饱和烃、芳香烃、非烃和沥青质四个族组分

## 2. 仪器原理简述

### 2.1 微波萃取与柱层析分离

微波萃取利用极性有机溶剂（二氯甲烷和甲醇）在密闭体系中吸收微波能、快速加热并加速溶剂对岩石粉末中有机质的溶解。相比索氏提取，微波萃取可将时间从数天缩短至 2 小时。

柱层析按化合物在硅胶（极性固定相）与不同极性溶剂（流动相）间的分配差异分离：非极性组分（饱和烃）被正己烷优先洗脱，芳香烃、非烃和沥青质极性递增，需使用更高极性混合溶剂依次洗脱。无水硫酸镁吸水，铜片与单质硫反应生成硫化铜以除硫。

### 2.2 气相色谱-质谱联用

气相色谱利用沸点差异在毛细管色谱柱中分离化合物——沸点低的先出峰，高的后出峰。质谱将化合物电离为碎片离子，按质荷比分离检测。两者串联：色谱先按时间分开混合物，质谱再对每个流出组分实时鉴定，获得总离子流图和特征质量色谱图。

生物标志物保留了原始生物母质的碳骨架，其特征离子碎片可用于选择性检测：正构烷烃的 m/z 85，萜烷（三环萜烷、藿烷、γ-蜡烷等）的 m/z 191，甾烷的 m/z 217。三重四极杆质谱比单四极杆多了第二级离子选择，选择性更高，适合痕量分析；常规烃源岩样品用单四极杆即可。

### 2.3 生物标志物分析的三个层次

以下参数主要用于课程中的典型 biomarker interpretation exercise。单个分子比值或峰群通常不是沉积环境、成熟度或生物来源的唯一判据；实际地球化学解释需要结合多个 biomarkers、maturity indicators、organic facies 和 geological context。

本实验涉及的三组谱图覆盖了有机地球化学四大功能（来源判别、环境恢复、成熟度评价、油源对比），按由浅入深可分三个层次：

1. **正构烷烃 + Pr/Ph**（m/z 85）— 快速判断有机质类型和沉积环境氧化还原条件
2. **萜烷/藿烷体系**（m/z 191）— 包括三环萜烷、藿烷、γ-蜡烷等，用于油源对比、沉积环境恢复和成熟度评价
3. **甾烷体系**（m/z 217）— 包括 C27/C28/C29 规则甾烷及甾烷异构化参数，用于生物来源判别和成熟度约束

## 3. 样品与实验条件

### 3.1 烃源岩有机质前处理

| 项目 | 内容 |
|------|------|
| 样品类型 | 烃源岩粉末 |
| 称样量 | 2–3 g |
| 萃取溶剂 | 二氯甲烷:甲醇 = 9:1（体积比） |
| 萃取方式 | 微波萃取仪，2 h |
| 萃取产物 | 氯仿沥青（可溶有机质） |
| 除硫方法 | 铜片反应，Cu 表面变黑即生成 CuS |
| 干燥方法 | 无水硫酸镁吸水，自然风干 2 天 |

### 3.2 柱层析分离条件

| 项目 | 内容 |
|------|------|
| 固定相 | 硅胶（150°C 活化），约 5 cm 高 |
| 吸水层 | 无水硫酸镁（150°C 烘干） |
| 底部垫层 | 脱脂棉 |
| 装柱结构 | 脱脂棉 → 无水硫酸镁 → 活化硅胶 |

**洗脱方案：**

| 组分 | 洗脱溶剂 | 用量 |
|------|---------|------|
| 饱和烃 | 正己烷 | 3 mL |
| 芳香烃 | 正己烷:二氯甲烷 = 7:3 | 7 mL |
| 非烃 + 沥青质 | 甲醇:二氯甲烷 = 1:1 | 3 mL（至流出液无色） |

### 3.3 GC-MS 分析条件

| 项目 | 内容 |
|------|------|
| 待测组分 | 饱和烃馏分 |
| 溶剂 | 正己烷 |
| 定容浓度 | 5 mg/mL |
| 进样量 | 1 μL |
| 进样口温度 | 280°C |
| 载气 | 高纯氦气 |
| 离子源 | 电子轰击 |
| 监测离子 | m/z 85（正构烷烃），m/z 191（萜烷），m/z 217（甾烷） |

### 3.4 实验流程

**前处理流程：**

1. 称取 2–3 g 粉末，加入二氯甲烷:甲醇 = 9:1 混合溶剂
2. 微波萃取 2 h，分离上清液与残渣
3. 上清液以 3000–4000 r/min 离心，取上清
4. 加入铜片静置除硫（铜片表面变黑即反应完成）
5. 自然风干 2 天，挥发溶剂，浓缩有机提取物，称量原质量
6. 装柱（脱脂棉 → 无水硫酸镁 → 活化硅胶）
7. 干燥后样品用少量二氯甲烷溶解，转移至柱顶（至少三次，至流出液无色）
8. 按洗脱方案依次接收各组分，自然挥发溶剂后称量
9. 要求各组分质量之和超过原有机提取物质量的 80%

**GC-MS 分析流程：**

1. 检查高纯氦气系统和真空系统
2. 调谐优化质谱参数，检漏（监测水和氮气含量）
3. 空白测试：进样正己烷检测系统污染
4. 饱和烃组分按 5 mg/mL 用正己烷溶解，涡旋震荡
5. 自动进样 1 μL，进样口 280°C
6. 色谱分离后质谱实时扫描，获得 TIC 和特征质量色谱图

## 4. 结果和分析

### 4.1 前处理结果

微波萃取可快速从烃源岩粉末中提取有机质。柱层析分离得到的四个族组分外观差异明显：饱和烃无色油状，芳香烃淡黄色至棕黄色，非烃和沥青质棕黑色粘稠状。质量损失主要来自溶剂挥发和器皿壁吸附。

### 4.2 正构烷烃分布（m/z 85）

课堂讲义给出的正构烷烃质量色谱图显示一系列规则排列的峰，主峰在 C19 附近，碳数范围 C15–C35，呈单峰钟形分布。主峰碳数偏低且单峰型，指示有机质以藻类和浮游生物来源为主（腐泥型，Type I/II）。若主峰在 C25–C29 且呈双峰，则指示高等植物输入为主（腐殖型，Type III）。

谱图中同时标出了姥鲛烷（Pr, C19）和植烷（Ph, C20）。Pr/Ph 由两者峰面积比计算。Pr/Ph 常被用作沉积氧化还原条件的经验 proxy：较低值在部分体系中常与较还原条件相关，较高值可与较氧化条件相关（课程中常用的经验性参考范围为 < 1 与 > 3）。但其解释同时受到有机质来源、成熟度、成岩作用和沉积体系影响，因此不能作为独立的氧化还原判据。该参数源于植醇（叶绿素侧链）在氧化条件下降解为姥鲛烷、在还原条件下加氢为植烷的路径差异。

谱图右侧标注了 α、β 和"同分异构"，解释的是 GC 中直链烷烃先出峰、支链和环状异构体后出峰的保留时间规律，由沸点和极性共同决定。

### 4.3 萜烷与藿烷分布（m/z 191）

m/z 191 质量色谱图中可识别的主要峰群：

- **三环萜烷**：色谱图前段 C20–C29 峰群，其中 C23 最强。三环萜烷来源于藻类膜脂，热稳定性高，常用于油源对比和成熟度评价
- **Ts/Tm**：三降藿烷的两个立体异构体。Ts/Tm 在 source/facies 相近的样品中可表现出 maturity sensitivity，但同时受到岩性、沉积环境和有机相差异影响，因此通常需要与其他成熟度指标联合解释。
- **C30 藿烷**：图幅中最高的峰，来源于细菌膜脂。藿烷整体指示细菌（原核生物）对有机质的贡献
- **γ-蜡烷**：峰位在 C30 藿烷之后，来源于纤毛虫细胞膜。γ-蜡烷/C30 藿烷比值 > 0.2–0.3 是课程/经验 interpretation：gammacerane 更稳妥地作为 water-column stratification 的 proxy；高盐环境是其常见背景之一，但不是唯一解释。
- **胡萝卜烷**：来源于藻类类胡萝卜素色素。高丰度胡萝卜烷 + 低 Pr/Ph + 高 γ-蜡烷，三者同时出现可共同指示咸水至超咸水的缺氧沉积条件

### 4.4 甾烷分布（m/z 217）

m/z 217 质量色谱图显示规则甾烷的分布。甾烷来源于真核生物细胞膜甾醇，是判别生物来源的核心参数。

**C27/C28/C29 规则甾烷：** 谱图中三个主峰群对应 C27、C28、C29 规则甾烷。C27/C28/C29 规则甾烷分布可提供有机质来源倾向信息，但单个碳数端元并不是某一生物类群的唯一诊断，解释时应结合其他生物标志物和地质背景（课程材料中常将 C27 与浮游藻类、C29 与高等植物输入相联系，仅作为经验性倾向）。

**甾烷异构化：** 谱图中标注了 ααα 和 αββ 构型。随成熟度升高，生物构型（ααα-20R）向地质构型（αββ-20S）转化，衍生出两个常用成熟度参数：

- C29 ααα 20S/(20S+20R)，平衡值约 0.52–0.55
- C29 αββ/(αββ+ααα)，平衡值约 0.67–0.71

两者联合使用可有效约束有机质热演化程度，与 Ts/Tm 互补。

## 5. 讨论

### 5.1 前处理质量控制

**除硫：** 铜片表面变黑是反应完成的直观标志。高硫样品若未除硫，硫化物会在色谱进样口沉积，严重干扰后续 GC-MS 分析。

**柱层析关键点：** 硅胶必须 150°C 活化，无水硫酸镁需烘干脱水，层析过程中保持硅胶层始终被溶剂覆盖（干裂即分离失败）。

**质量回收率约束：** 各组分质量之和需超过原提取物质量的 80%，低于此值说明转移或挥发损失过大，样品不宜进 GC-MS。

**防污染：** 器皿用锡纸包裹防光降解和有机物吸附，玻璃仪器需高温烘烤，风干在洁净通风处进行。

### 5.2 三芴能否作为地层对比指标

课堂讨论涉及三芴的地层应用问题。三芴指芴、氧芴、硫芴三种三环芳烃，在沉积有机质中广泛存在。硫芴在碳酸盐岩和蒸发岩中相对富集，氧芴在煤系中较高，因此 DBT/P 比值可用于区分海相与陆相原油。

但作为地层对比工具的局限性在于：三芴分布于芳香烃而非饱和烃馏分，本实验仅分析饱和烃；三芴丰度远低于甾烷和藿烷，不适合精细地层对比；三芴的指相意义更多是全局性的海相 vs 陆相判别。因此精细地层划分和油源对比仍应以三环萜烷和甾烷为主。

### 5.3 生物标志物参数的整体框架

课堂笔记中三张谱图（正构烷烃 → 萜烷 → 甾烷）实际上构成了一个由粗到细的分析体系：

- **第一层**（m/z 85）：正构烷烃分布 + Pr/Ph，快速判断有机质类型和环境氧化还原状态，操作直观但信息量有限
- **第二层**（m/z 191）：萜烷/藿烷体系，提供油源对比、沉积环境恢复和成熟度信息。三环萜烷热稳定性高，在过成熟样品中仍可识别；藿烷则在高成熟阶段可能大量降解消失
- **第三层**（m/z 217）：甾烷体系，提供最精细的生物来源判别和独立的成熟度约束。甾烷/藿烷比值直接反映真核与原核生物的相对贡献

实际研究中这三层参数通常组合使用，互相验证。

### 5.4 实验局限性

本次实验未提供实测谱图数据，以上讨论基于课堂讲义中的谱图草图和文献中生物标志物参数的一般性地质含义，属于方法学层面的整理，未涉及具体样品的实际测试结果。

## 6. 结论

- 微波萃取-柱层析分离流程可从烃源岩粉末中有效提取并分离饱和烃、芳香烃、非烃和沥青质四个族组分。铜片除硫、硅胶活化和防干裂是影响分离质量的关键因素
- 饱和烃生物标志物的 GC-MS 分析可按三大体系展开：正构烷烃（m/z 85）判有机质类型与环境氧化还原条件；萜烷/藿烷（m/z 191）用于油源对比、环境恢复和成熟度评价；甾烷（m/z 217）用于生物来源判别和成熟度约束
- Pr/Ph 比值可作为氧化还原条件的经验 proxy；γ-蜡烷和胡萝卜烷可提供古盐度与水体分层的经验指示；Ts/Tm 和甾烷异构化参数（20S/(20S+20R)、αββ/(αββ+ααα)）常作为热成熟度的经验指标；C27/C28/C29 规则甾烷分布可提供有机质来源倾向信息
