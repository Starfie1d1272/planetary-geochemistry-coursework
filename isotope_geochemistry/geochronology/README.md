# 同位素定年方法思考题
> Coursework artifact · Nanjing University · 2026  
> Original course module: Isotope Geochemistry · HW3 · geochronology methods

## 1. 定年的基本公式和一般前提

放射性衰变遵守一阶动力学：$-\frac{dP}{dt} = \lambda P$，积分得到：

$$ t = \frac{1}{\lambda} \ln\left(1 + \frac{D}{P}\right) $$

使用这个公式的前提：
- **封闭体系**：矿物形成后母体和子体没有进出
- **衰变常数 $\lambda$ 已知且准确**
- **能确定初始子体含量**：公式里的 $D$ 只算衰变新生成的部分
- **半衰期与样品年龄量级匹配**：$^{14}\text{C}$ 不能定亿年岩石，$\text{U-Pb}$ 不能定百年样品

## 2. 等时线年龄与模式年龄的差别

**模式年龄**：测一个样品，假设初始子体比值为已知值，直接算年龄。方便但初始比值猜错了就会偏。

**等时线年龄**：测一组同源样品，将 $^{87}\text{Rb}/^{86}\text{Sr}$ 对 $^{87}\text{Sr}/^{86}\text{Sr}$ 作图，斜率给年龄，截距给初始比值。

等时线的优势：
- 不需要事先知道初始比值
- 数据点共线本身就验证了封闭体系假设，点不散说明体系没被扰动
- 多个样品互相校核，比单个样品可靠

## 3. Rb-Sr 和 Sm-Nd 定年适合的矿物和岩石

**Rb-Sr**（$^{87}\text{Rb}\to ^{87}\text{Sr}$，$t_{1/2}=488$ 亿年）：
- 含 K 矿物：白云母、黑云母、钾长石（Rb 替代 K 进入晶格，Sr 少 -> 母体/子体比值高）
- 岩石：花岗岩、花岗闪长岩等长英质火成岩
- 不适合：碳酸盐岩、基性岩（Rb 太低 -> 母体/子体比值小 -> 误差大）

**Sm-Nd**（$^{147}\text{Sm}\to ^{143}\text{Nd}$，$t_{1/2}=1060$ 亿年）：
- 矿物：石榴石（Sm 优先进入，Sm/Nd 高）、榍石、磷灰石、辉石
- 岩石：玄武岩、辉长岩、橄榄岩等基性/超基性岩；榴辉岩
- 优点：Sm-Nd 在水热流体里活动性差，抗后期扰动能力强，比 Rb-Sr 更扛变质作用
